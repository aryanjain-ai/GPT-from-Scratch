# GPT From Scratch (Bigram → Transformer)

This project implements a GPT-style language model using PyTorch.

The model was built step-by-step to understand:
- Token embeddings
- Positional embeddings
- Masked self-attention
- Multi-head attention
- Transformer blocks
- Training loops
- Text generation

## Model Architecture
- Decoder-only Transformer
- Multi-head self-attention
- Layer normalization
- Feedforward network
- Cross-entropy loss

## Dataset
Trained on text corpus (Wizard of Oz / similar dataset).

## Technologies Used
- Python
- PyTorch
- NumPy
- Google Colab

## Status
Completed and will soon train on other text corpus and understand techniques of data ingestion
